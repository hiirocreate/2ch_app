# 2ch_app — スレまとめビューア + 神スレAI動画化

5ch（なんJ / VIP / ニュー速+）・おーぷん2ch（おんJ / おーぷんVIP）の人気スレを
リアルタイム・過去ランキングで閲覧し、「神スレ」を AI 台本＋読み上げ＋BGM＋挿絵で動画風に再生する PWA。

## 起動
```bash
npm install
npm start          # http://localhost:3000 （実際の掲示板を巡回）
npm run demo       # ネット不要のデモデータで起動
npm test
```
スマホはホーム画面に追加すればアプリとして使える（PWA）。

## 機能
| タブ | 内容 |
|---|---|
| リアルタイム | 各板の subject.txt を5分ごとに巡回し「勢い（レス/日）」順に表示 |
| 過去の人気 | 巡回履歴の最大勢い順。神スレ判定したスレは本文を保存するので dat 落ち後も閲覧可 |
| 神スレ動画 | 神スレ度（盛り上がり・イッチへの注目・称賛レス・被アンカー等）が閾値以上のスレ。タップで動画再生 |

- 下部の入力欄に `…/test/read.cgi/板/スレキー/` の URL を入れると過去スレも追加・判定・動画化できる。
- 動画: 台本生成 → Canvas で「挿絵(Pollinations.ai) + 字幕 + 話者別の読み上げ(Web Speech API) + 雰囲気別の自動作曲BGM(Web Audio)」を再生。

## 動画台本の AI 生成
`ANTHROPIC_API_KEY` を設定すると Claude（既定 `claude-opus-5`、拒否時はサーバー側フォールバック有効）がハイライトから台本・BGMの雰囲気・挿絵プロンプトを生成。未設定時はルールベース台本。

## 環境変数
| 変数 | 既定 | 説明 |
|---|---|---|
| `PORT` | 3000 | |
| `ANTHROPIC_API_KEY` | - | AI台本生成 |
| `CLAUDE_MODEL` | claude-opus-5 | |
| `CRAWL_INTERVAL_MIN` | 5 | 巡回間隔（分） |
| `KAMI_THRESHOLD` | 55 | 神スレ判定の閾値(0-100) |
| `BOARDS_JSON` | - | 板定義の上書き（ホスト移転時など。`server/sources.js` の形式） |
| `DATA_DIR` | ./data | 保存先 |

## 注意
- 巡回は低頻度・少数件に抑えている。各掲示板の利用規約（転載・機械取得の可否）を確認のうえ、個人利用の範囲で使うこと。公開配信する場合は転載許可のある板か、専用API契約が必要。
- 5ch は dat 直接取得が制限されているため read.cgi の HTML 解析にフォールバックする（レイアウト変更で要修正の可能性あり）。
